# The Curious Chronicle — Portfolio Starter

An original magical-vintage newspaper inspired React + Vite + TypeScript portfolio starter for Swikriti Das Biswas.

## Get started on Windows (VS Code)

1. Extract the ZIP (don't open the code from inside the ZIP).
2. In VS Code choose **File → Open Folder** and select `curious-chronicle-starter`.
3. Open **Terminal → New Terminal**.
4. Run:

```powershell
npm.cmd install
npm.cmd run dev
```

5. Open the local URL Vite prints (usually `http://localhost:5173/`).

`npm.cmd` deliberately avoids the PowerShell `npm.ps1` execution-policy error. You do **not** need to change your Windows execution policy.

## Where things live

- `src/App.tsx` — the starter homepage and page sections.
- `src/styles.css` — all styles, paper textures, typography, responsive design.
- `src/data/content.ts` — name, masthead headline, story titles.
- `public/` — future photos, project images, illustrations.
